How the tumble multiplier progresses

Every free spin begins at the feature’s current starting multiplier. When a winning combination tumbles away and another win forms, the multiplier doubles. For example, an 8x start can progress to 16x, 32x and 64x across consecutive winning tumbles within that spin.

When the next free spin begins, the progressive value resets to the starting multiplier. It does not return to 1x as it does in the base game, and it does not preserve the highest tumble value from the previous spin.

Why “reset to ten” matters

Landing three or more Scatters during free spins resets the remaining spin count to ten rather than simply adding a fixed number. The same event also multiplies the starting multiplier by a value tied to the number of Scatters. The official game page describes 3-6 Scatters multiplying the starting value by 2x-16x.

Example

If two spins remain and a qualifying Scatter retrigger occurs, the counter returns to ten. If nine remain, it still returns to ten; it does not add ten. The timing therefore changes the number of extra spins received.

How the pre-feature gamble connects

Before the feature begins, the optional gamble can attempt to double the awarded starting multiplier, potentially up to 256x. Losing can forfeit entry. It is separate from the Scatter retrigger that can later raise the starting value during free spins.

What free spins do not guarantee

  • A starting multiplier does not pay unless a qualifying win lands.
  • Ten spins do not guarantee a retrigger or a long tumble sequence.
  • A previous dry feature does not make the next feature stronger.
  • The 10,000x maximum is a ceiling, not a typical bonus result.
  • Buying or triggering the feature does not remove volatility.

Reading the multiplier counter during a feature

The counter above the reels is the clearest signal the game gives you, and it is worth understanding what it is actually reporting. It displays the multiplier that will apply to the next qualifying win in the current sequence. It advances only when a win forms after a tumble, and it resets when a spin resolves without one.

This is why two features that start identically can diverge so sharply. A round that opens at 32x and produces single wins with no follow-on tumbles never advances past its starting value. A round that opens at 8x but chains five consecutive tumbles passes it comfortably. The starting multiplier sets the floor; the tumble chain determines everything above it.

Retriggers in practice

Landing further Scatters during the feature resets the remaining spin count back to ten and can increase the starting multiplier. The practical effect is that feature length is not fixed at entry — a round can extend well beyond its initial ten spins. This also means a feature's eventual return is not predictable from its opening, which is worth remembering before deciding a round has "gone wrong" four spins in.

What a retrigger does not do is guarantee anything. It restores spins and may raise the starting value; it does not make wins more likely on those spins, and it does not alter the game's published ceiling.

Using free play to learn the sequence

The feature has enough moving parts — starting multiplier, tumble progression, retriggers, the optional pre-feature gamble — that learning it with money on the line is unnecessarily expensive. A legal free demo runs the same rules and lets you watch the sequence resolve without cost.

The limit of that approach is important: demo outcomes illustrate mechanics, not probabilities. A handful of demo features cannot tell you how often a result occurs, and a good demo run is not evidence about real-money sessions. Use it to learn what the buttons do and how the counter behaves, then stop drawing conclusions there.
